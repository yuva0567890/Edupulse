Why this model

TF-IDF + Logistic Regression is fast, runs fully offline, needs no GPU and — crucially for this project — is explainable: each term’s contribution is tf-idf × coefficient, which powers the “Why?” panels. Combined with Unicode normalisation, Tanglish/Hinglish normalisation and a shared English concept space, one model serves Tamil, Hindi, English and code-mixed text. A fine-tuned XLM-RoBERTa can be plugged in with python training/train.py --transformer; the app then switches to “Multilingual Transformer” mode automatically.

Limitations & challenges

  • Dataset: bundled data is synthetic and small; real feedback is noisier and more varied.
  • Multilingual: Tamil is agglutinative (many suffixes) and Hindi has several spellings of the same word; the lexicon covers common forms only.
  • Tanglish: Romanized spelling is not standardised (romba / rombha / rmba); unseen spellings fall back to raw tokens.
  • Code-mixing: language switches inside a clause are handled through concept normalisation, not true cross-lingual understanding.
  • Sarcasm, negation scope and unseen vocabulary can cause errors; confidence is a model probability, not a guarantee.
